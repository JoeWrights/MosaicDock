# Mosaic Dock

Mosaic Dock is a pnpm + Turbo monorepo refactor based on `guada`.

## Stack

- Frontend: React, Ant Design, Rsbuild
- Backend: NestJS, Prisma, SQLite
- Workspace: pnpm, Turbo

## Commands

```bash
pnpm install
pnpm dev:web
pnpm dev:api
pnpm test
pnpm typecheck
pnpm build
```

For migration details, deployment notes, and Electron follow-up scope, see `docs/migration/README.md`.
